# Nehul
## Projeto para o desenvolvimento de um site para o Nehul (Núcleo de Estudos em Humanidades e Linguagens), um grupo de pesquisa vinculado ao IFPB Campus Santa Rita. O site consiste em realizar a criação de projetos e visualização dos projetos.

## Principais funções do site:
- Criar projetos com suporte a imagens e links de vídeos **( somente admin )**
- Visualizar projetos que já foram realizados
- Visualizar projetos em andamento
- Visualizar projetos que serão realizados futuramente
- Exclusão dos projetos **( somente admin )**

## Para a adição de novos projetos, mudança de estado dos projetos e exclusão dos projetos são apenas realizados com o acesso do admin.

## O banco de dados utilizado foi o PostegreSQL do site do Supabase aonde estão sendo armazenadas todas as mídias dos projetos.

## O site também tem uma página dedicada ao Heliton Santana que foi um importante ativista da Paraíba que defendeu seus direitos.
